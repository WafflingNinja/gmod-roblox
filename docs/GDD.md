# Game Design

## Pitch
Gmod's sandbox spirit, built for Roblox: spawn anything, build contraptions, break everything, with friends and strangers in one big freeroam world.

## Pillars
1. **Physics is the toy.** Everything is a real unanchored part you can grab, weld, throw, and break.
2. **Instant fun.** Join, press Q, click, something is on screen in 3 seconds.
3. **Crazier than Gmod.** Breakable props, a gun roster, NPCs, silly animations, ragdolls.
4. **Safe to share.** Ownership, caps, and server validation keep one player from ruining the server.

## Scope
**In:** freeroam sandbox, spawn menu, tools, premade cars, ragdolls, dupes (save/load builds), breakable props, gun roster, NPC AI, emotes, posable ragdolls.

**Out (for now):** gamemodes (Prop Hunt, TTT), user-made content, mobile/console, monetization.

## Core loop
Spawn props -> combine with tools -> test (drive, throw, blow up) -> save as dupe -> share the chaos.

## Players
Public from day one. 16-24 per server. PC only. Each player owns what they spawn (cap 150).

## Controls (planned)
| Key | Action |
|---|---|
| Q | Spawn menu |
| X | Remove aimed prop |
| 1-3 | Physgun, gravity gun, toolgun (step 2) |
| C | Context menu (step 2) |

## Map
One large flat map, themed areas added later. Baseplate 2048x2048 for now.

## Success
A friend joins, spawns a car from wheels and planks, drives it, and tells someone else to join.
